# Publishing the dashboard to the Grafana community catalog

`open5gs-observatory.grafana-com.json` is a ready-to-share copy of the *Open5GS Observatory* dashboard.
It is generated by `python3 grafana/export_for_grafana_com.py` and differs from the provisioned dashboard only in that
the hard-coded datasource is replaced by the import input `${DS_PROMETHEUS}` (Grafana asks the importer to pick *their* Prometheus).
It was test-imported into a clean Grafana: 41 panels (incl. rows), none left with an unresolved datasource.

## Upload (needs your own grafana.com account — it cannot be done for you)

1. Sign in at <https://grafana.com> (free account).
2. **My dashboards → Upload dashboard**, choose `open5gs-observatory.grafana-com.json` (a *Classic* JSON model is required).
3. Fill in the metadata (suggested text below) and click **Save and Publish**.
4. The public page can take several hours to appear.

Alternative that never touches this file: in your running Grafana open the dashboard → **Export → Export as code →
Classic**, switch on **Share dashboard with another instance**, download, and upload that.

## Suggested listing text

**Title:** Open5GS 5G SA Core - User-plane Observatory

**Short description:** End-to-end view of an Open5GS + UERANSIM 5G standalone testbed: NF health, registered UEs and PDU sessions,
uplink/downlink throughput at the UE, UPF and server (to see exactly where packets are lost), per-NF CPU/memory, and N6 queue backlog/drops.

**Tags:** `5g`, `open5gs`, `ueransim`, `telecom`, `core network`, `prometheus`

**Requirements (put this in the description — otherwise people will see empty panels):**
* Prometheus scraping the native Open5GS metrics of AMF/SMF/UPF/PCF (`:9091`), node_exporter, and the
  `ibg_*` exporter from <https://github.com/Pouria-Arefijamal/Intent_Based_Graphana_for_Open5Gs> (`exporter/`, port 9200).
* Grafana 11+ . Datasource type: Prometheus.
* Note: Open5GS's own `fivegs_ep_n3_gtp_*` UPF packet counters are stubs (always 0), so user-plane throughput comes from the exporter.

## Other places a contribution can go

* **Grafana itself** (`github.com/grafana/grafana`): code/doc fixes via pull request; you must sign Grafana's CLA when you open it
  (a bot prompts you). Dashboards like this one are not code contributions — their home is the community catalog above.
* **The Open5GS Docker packaging we build on** (`herlesupreeth/docker_open5gs`) ships a `grafana/` folder; a pull request adding
  this dashboard there would help its users. Only do this with the exporter metrics documented in the PR.
